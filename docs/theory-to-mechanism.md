# From international-relations theory to executable mechanisms

## The translation discipline

Game of International Life does not treat a theorist's name as an implementation specification. Every theory-bearing module must make the following chain inspectable:

> theoretical assumptions → actor state → available information → decision rule → interaction process → macro observable → failure condition

A model should distinguish at least three kinds of claims:

1. **Software claim:** the code implements the declared rule correctly.
2. **Generative claim:** the rule can produce a specified pattern in an artificial world.
3. **Empirical claim:** the rule explains or predicts documented historical evidence better than alternatives.

The current repository supports the first two. It does not yet make the third.

## Shared modeling vocabulary

### Cell

A stable location or strategic site on a lattice. Its geographic identity persists even when political control changes.

### Polity

An actor controlling one cell in M1 or a connected set of cells in M2 and later worlds. A polity can aggregate resources, hold treasury, issue actions, lose territory, disappear, or fragment into successors.

### Relation

A non-geographic tie such as an alliance, rivalry, or institutional commitment. Relations should be represented as graph edges rather than smuggled into spatial adjacency.

### System

The distribution of capabilities, territories, borders, relations, and interaction patterns produced by all actors. Polarity is a system-level measurement, not an actor label.

## Jervis — Offense, defense, signaling, and spirals

### Theoretical ingredients

- anarchy and self-help;
- uncertainty or ambiguity about others' postures;
- offense–defense balance;
- distinguishability of offensive and defensive postures;
- reciprocal security responses;
- deterrence and spiral dynamics.

### M1 representation

| Concept | Executable representation |
|---|---|
| Polity | One square-lattice cell |
| Capability | Discrete arms level |
| Posture | Fixed offensive or defensive attribute |
| Strategic neighborhood | Eight-cell Moore neighborhood |
| Distinguishability | Weight suppressing threat attributed to defensive neighbors |
| Offense advantage | Relative multiplier on attack and defense effectiveness |
| Spiral | Growth in arming generated by reciprocal local threat response |
| Conflict | Threshold event when attack capacity exceeds local deterrence |

### Interventions

- vary distinguishability while holding the initial world fixed;
- vary offense advantage while holding posture and arms fixed;
- compare the four high/low combinations;
- sweep the continuous parameter surface;
- inspect both final arms and conflict trajectories.

### Failure condition

The mechanism is not live if distinguishability changes only labels, if offense advantage does not affect action incentives, or if arming outcomes are hard-coded independently of neighborhood perception.

### Current limits

M1 has no territory, bargaining, learning, alliances, or endogenous posture. M5 will move Jervisian uncertainty into the territorial world.

## Waltz — Structure, survival, and security seeking

### Theoretical ingredients

- anarchy as the system's ordering principle;
- functionally similar units;
- variation primarily in capability;
- survival and self-help;
- competition, socialization, and systemic selection;
- internal and external balancing;
- polarity as a distributional property.

### Computational implications

A Waltz-inspired experiment should minimize gratuitous differences in actor psychology. Units should face common rules and differ primarily in position, resources, and capability. Structural conditions, rather than bespoke personalities, should do explanatory work.

Candidate structural interventions include:

- initial capability concentration;
- number of major powers;
- resource geography;
- border topology;
- costs of power projection;
- alliance availability;
- defensive advantage;
- rates of capability conversion.

### M3 proxy

M3 does not implement the full theory. It operationalizes one defensive-realist proposition as a **security-sufficiency stopping rule**:

```text
security ratio = own capability / strongest adjacent rival capability
```

A polity below the threshold may exploit a feasible local action to repair vulnerability. A polity at or above the threshold abstains, even if further conquest would increase its relative power.

This is a deliberately narrow proxy. It omits peaceful internal balancing, alliance formation, socialization, emulation, and the broader system-wide logic of balancing.

### Candidate observables

- survival of original states;
- expenditure required to maintain security;
- capability concentration and effective powers;
- balancing and counter-concentration;
- frequency of security-repair actions;
- cessation of expansion after sufficiency;
- persistence of different polarity structures.

### Failure condition

A model is not meaningfully Waltzian if it explicitly commands actors to create bipolarity or balance. The distribution must emerge from common rules and structural constraints rather than being an actor's target state.

## Mearsheimer — Relative power and regional hegemony

### Theoretical ingredients

- anarchy;
- offensive military capability;
- uncertainty about intentions;
- survival as the primary goal;
- strategic rationality;
- incentives to maximize relative power;
- regional hegemony as the safest position available.

### M3 proxy

M3 operationalizes one contrast with security seeking. The power-maximizing policy values:

- favorable local force ratios;
- productive territory;
- expected relative capability gains;
- weakening powerful rivals;
- opportunities that remain after immediate security sufficiency.

The key difference is:

```text
security seeker:     stop when sufficiently secure
power maximizer:     continue while favorable relative gains remain
```

The rule uses the same attack threshold and battle engine as the security seeker. It is not granted a more permissive world.

### Candidate observables

- attacks after security sufficiency;
- opportunistic and preventive war;
- conquest and territorial turnover;
- emergence of dominant regional powers;
- capability HHI and largest power share;
- systemic war cost;
- survival of power maximizers and their neighbors;
- balancing reactions once alliances are introduced.

### Failure condition

The comparison is invalid if the offensive-realist proxy simply receives stronger weapons, lower costs, better information, or a friendlier geography. The theory-specific treatment must reside in objective and choice, not in hidden environmental advantages.

## M3 matched contrast

M3 compares the two proxy rules under:

- balanced versus dominant-power initial capability distributions;
- diffuse versus clustered resource fields;
- matched territorial maps;
- exact shared initial fingerprints;
- encounter-keyed common random numbers.

The first discriminating observable is **attacks while secure**. It directly tests the stopping-rule difference before downstream feedback is interpreted.

The experiment then measures war cost, conquest, concentration, extinction, fragmentation, and state survival. Similar final outcomes can therefore be separated by process.

Read [`m3-structural-comparison.md`](m3-structural-comparison.md) for the complete specification.

## Snyder — Alliance security dilemmas

### Theoretical ingredients

- alliances as conditional commitments under uncertainty;
- dependence and asymmetry among partners;
- fear of abandonment;
- fear of entrapment;
- bargaining over support and restraint;
- alliance choices conditioned by polarity and adversary relations.

### Required representation

A fixed-neighborhood CA is insufficient because allies need not share a border. M4 should be a **networked cellular automaton**:

```text
territorial lattice + dynamic alliance graph
```

### Local alliance state

- partner set;
- commitment strength;
- dependence on each partner;
- perceived reliability;
- adversary alignment;
- assistance cost;
- abandonment exposure;
- entrapment exposure.

### Local decisions

- tighten or loosen commitment;
- support, partially support, or withhold support during a crisis;
- seek a new partner;
- leave an alliance;
- balance, bandwagon, or pass responsibility;
- attempt to restrain an ally.

### Macro observables

- alliance bloc formation;
- abandonment and entrapment rates;
- chain-ganging conflict cascades;
- buck-passing;
- alliance durability and turnover;
- conflict diffusion;
- systemic differences between bipolar and multipolar alliance structures.

### Crucial trade-off and failure condition

Increasing commitment should reduce some abandonment risks while raising the probability or cost of entrapment. A model in which stronger commitments improve reliability without any corresponding constraint or liability has removed the alliance security dilemma it claims to study.

## Cross-theory experiments

The strongest experiments hold the artificial world fixed and vary only the mechanism in question:

- security sufficiency versus continued relative-power accumulation;
- reassurance-sensitive actors versus worst-case threat responders;
- flexible versus unconditional alliance commitments;
- internal balancing versus alliance balancing;
- homogeneous rules versus mixed theoretical ecologies;
- hand-coded theory rules versus evolved programs.

A theory can fail in several precise ways:

- it does not generate its expected pattern;
- it generates the pattern only in a narrow parameter region;
- a rival mechanism generates the same pattern more robustly;
- aggregate outcomes fit while process traces do not;
- results collapse under small topology or information changes;
- the mechanism's signature cannot be distinguished from a simpler baseline.

## From theory baselines to evolutionary search

Hand-coded theories should become seeds and baselines for later GA/GP work. A candidate rule representation should expose named features such as:

- own and rival capability shares;
- security ratio;
- border length;
- local offense–defense ratio;
- resource value;
- alliance reliability;
- abandonment and entrapment exposure;
- recent conflict history;
- signal credibility.

Evolution may then discover:

- altered thresholds;
- context-sensitive stopping rules;
- hybrid security and power objectives;
- conditional reassurance;
- alliance strategies that switch between restraint and commitment;
- stepping stones toward stable orders not anticipated by the initial theories.

The scientific payoff is not “AI beat Waltz.” It is a compact, stress-tested policy program whose behavior can be translated into a new theoretical conjecture.
